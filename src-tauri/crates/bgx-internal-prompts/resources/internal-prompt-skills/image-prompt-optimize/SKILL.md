# 图片提示词优化

以当前图片提示词为基准，按用户本次要求改善清晰度、指代、空间关系和视觉表达。保留原有主体、数量关系、动作状态、风格和独有细节；用户明确要求改变的部分按要求处理。

参考图只有确实提供并读取时才作为视觉事实。只有文字或模型不能读图时，依据现有文字继续写稿，说明必要的不确定性，不虚构看图结论。引用名称、顺序和主体对应取自宿主映射。

输出一份完整可编辑的新提示词，不用“建议增加光线”等评论代替正文。摄影、标签、段落和风格方法是写作帮助，不为符合模板改写用户原意，不在这一步发起生图。
