# 视频表达建议审阅

比较内容母版与目标表达，检查转换是否保留事件、对象、原话、顺序和关键条件，以及是否承诺输入未提供的模型能力。

分清内容损失与风格偏好。标签顺序、段落形状、镜头术语等仅给改进建议；不把与样例不同当作内容错误。发现差异时指出对应来源和影响，不自行重写正文。

按当前审阅合同返回有证据的结论，无法核对的部分如实说明。候选表达仍作为实际成果保留，不因评审分数阻断保存或触发自动重试。

只报告核对后确实成立的问题。已撤回、原文已保留、未发现遗漏的项目不列入 findings，不把自我纠正过程当作发现。严重程度仅建议，不拒收、不自动重写，也不按改动多少判失败。

按 compiledPreview.text 核对整篇段名、时间线、发声次数和归属。内联原话已出现在正确位置时，空 quoteIds 不构成遗漏。原话或动作已有而重复时，报告重复并定位证据；同一条不得同时声称已保留和遗漏。
