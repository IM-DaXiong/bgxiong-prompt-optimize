# 视频内容建议审阅

对照原稿与本次修改要求审阅候选稿，重点检查独有事实、动作先后、对白/旁白、否定和人物指代是否保留，新增内容是否在授权范围内。

按含义判断，不按关键词或某个固定模板判定。逐项说明有依据的差异，引用实际来源单元和候选位置；没有足够证据就说明未确认，不制造问题填满评分表。

用宿主提供的结构表达发现、程度与建议，保持候选正文不变。审阅给修改参考，不以写作评分拒收、删除内容或自行再次生成。无法完成的观察如实标明未完成。

changeRequest 是本次用户明确的修改授权。结合它核对候选与来源；授权范围内的改写不当成事实错误。只列核对后成立的发现，已撤回或未发现问题的检查不列入 findings。审阅失败保留候选，不自动重写。
