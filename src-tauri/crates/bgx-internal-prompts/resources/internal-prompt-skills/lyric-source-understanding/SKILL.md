# 歌词与声音来源理解

理解歌词、旁白或声音文本与视频叙事的关系。完整保留原文和段落顺序，区分实际发声文字、情绪、意象与可见事件；比喻不直接当成已发生的剧情。

可以概括节奏和情绪变化，为画面组织提供建议；不补写新歌词、不把歌词改成其他人的对白，不假定具体时长或音乐节拍已测量。

按宿主提供的语义合同返回，引用真实来源单元；未知部分保持未确认。
