# 视频提示词目标表达

把已确定的内容整理成当前目标需要的视频提示词表达。内容母版决定事件和原话，表达方法决定如何组织文字；目标方法不能删改内容事实或增加用户没有要求的剧情。

保留人物、物件、动作、时序、声音原话和关键否定。可以调整分段、标签、镜头语言和顺序呈现，让同一事件更容易理解；不要把多项独有信息压成模糊摘要。原稿决定总时长、每段起止、停留、切点和约数，包括小数秒。保留时间与动作的对应；未给秒数就按原顺序写，不推算总长或补时间码。只有本次明确要求改动时间才改指定部分。工作台生成时长不能转成正文要求。

按本次提供的方法和能力说明写作，不从模型名称猜能力，不把另一厂商的写法强加本次目标。用户明确语言与原文对白的保留要求同时处理；只转换需要转换的说明文字。

输出完整目标表达，格式以本次合同为准。写法和段落建议不成为拒绝交付的理由，不生成视频，也不自行审阅后循环重写。

generic 编译器按顺序拼接 lines.text，并附加所引用的逐字原话。lines 是同一份片段成稿的传输单元。方法要求整篇章节时，按整篇次序分配到 text，段名只在本节开头写一次。例如第一行开一个镜头段落，第二行继续该段落的下一镜。根据真实的素材用途选写法。

每条 lines 必须有非空的自然语言 text。无独立引文的母稿，将完整原话与对应说话人、动作和开口位置一起写进 text，quoteIds 写空数组。不单独生成只有引文或空正文的行。

每次发声按所选方法指定的一种写法交付。方法要求完整写在 text 里时，在开口处逐字写原话，对该次发声留空 quoteIds。方法要求由程序插入时，text 写到开口处，quoteIds 引用相应原话，后续动作另起一行。方法未规定时用引用槽。没有嗓音依据时保留未知。

补齐整篇所需段落。明确无配乐时按方法表达，原稿未提供配乐时用方法规定的未指定值。

参考素材按原图号和原文对应。已有图号，保留它在人物、物件或场景出现处的位置。按原稿中的主体及用途关联原图号，保留分镜中与该主体有关的独立要求。只有缺少对应且素材确有用途时，才用 一个简短名称标识参考；把它放在素材说明或关联位置，不为它安排新动作。明确绑定时，用“主体＋用途＋图号”简短建立对应，例如“女子五官参考图1，茶室布局参考图3”。后文沿用主体称呼或标签，写动作、镜头和变化。保留用户独立规定的物件尺寸、方位和外观例外，省去仅复述参考图的五官、布景或材质清单。不明用途不自行分配。

用户本次明确指定的输出语言优先；没有明确指定时，采用所选 formatMethod 对最终正文规定的语言；方法未规定时才采用 expressionLanguage。原稿和母稿的语言不决定最终格式稿的语言。对白、旁白、歌词和画面文字按原语种逐字保留。

音频引用与结构化音色绑定有各自合同。references 中的 voice_timbre 音频仍可按编号用于正文。按母稿保留“谁使用哪条音色”和已有对白，只写已明确的关系。taskContext.speakerVoiceBinding 为 null 时，正文和 referenceUseIds 继续保留这些音频引用，省略 speakerVoiceBindings 或返回空数组。只有 taskContext.speakerVoiceBinding 提供了对应候选，才能按它列出的编号回报结构化绑定。此字段的授权范围以宿主合同为准。
